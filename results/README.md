# Resultados

`ieee123/` contém a execução S0–S4 com pandapower, gerada por `evcs-demo --output results/ieee123`. Os manifestos identificam dados, backend e aproximações. Resultados gerados são ignorados pelo Git.

`demo_reference/` contém resultados sintéticos históricos da versão inicial; não representa a simulação padrão atual. O destino padrão do CLI continua sendo `results/demo/`.
