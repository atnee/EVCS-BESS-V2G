# Reviewer guide: Applied Energy manuscript (EVCS, BESS and V2G on the IEEE 8500 feeder)

This page tells reviewers where the code, data and figures behind each part of the manuscript are. The manuscript itself is not in this repository. Ask the authors for it.

**Branch:** `feature/sensibilidade`. Most other documents in the repository are in Portuguese (the team's working language). The code, docstrings and figure text are in English.

## Two electrical models: read this first

The study uses two network representations. Their results are not interchangeable:

| Manuscript part | Model | Where |
|---|---|---|
| (a) EVCS planning and impact, S0/S1 · (b) integrated scenarios S0–S4 and 63-configuration sensitivity · Figs. 2–8, Tables 1–12 | **pandapower**, IEEE 8500 medium-voltage reduction (`runpp_3ph`) | `src/`, `configs/`, `paper/` |
| (c) model-transfer diagnostic (historical single-site resources replayed) · (d) distributed BESS–V2G configuration · Figs. 9–11, Tables 13–16, S1–S6 | **OpenDSS**, full IEEE 8500 feeder (physical phases, secondary network, native controls) | `opendss_rebuild/`, `distributed_stochastic/`, `validation_applied_energy_final/` |

The findings depend on the model used. They do not certify that the feeder is feasible as a whole. The voltage limits (0.95–1.05 p.u., ANSI C84.1 range A) and the thermal limit (100 %) are reference values. They are not Honduran regulations.

## What is and is not in the repository

The repository includes:
- all the code;
- the curated `paper/` snapshot;
- the OpenDSS audit scripts and reports (`validation_applied_energy_final/*.md`, numbered 01–11);
- the summary tables and manifests;
- the plotted data of the revised figures.

It does **not** include:
- `results/`, the raw simulation outputs. Each one is regenerated by the commands below. The raw OpenDSS replays are several hundred MB of hourly voltage and branch tables. Only their `manifest.json`, `summary`/`comparison` CSVs and logs are kept, so the SHA-256 values in the manifests identify the exact files used.
- the manuscript.
- intermediate patch archives (`*.zip`, `*.rar`).

**Edits made for publication:** the local user path at the start of absolute paths in manifests and logs was replaced by `<root>` or `<user-home>`. Nothing else in those files was changed. The paths inside the manifests refer to the authors' workspace, where the pandapower project and the OpenDSS project were sibling folders. In this repository both are at the root.

## Reproducing

```powershell
python -m venv .venv; .venv\Scripts\activate
pip install -e ".[dev]"
pip install opendssdirect.py==0.9.4        # only for the OpenDSS part (c)/(d); not in pyproject.toml
```

| Step | Command (repository root) | Time |
|---|---|---|
| Fast tests (figures, BESS, V2G, strategies) | `python -m pytest tests/test_bess.py tests/test_v2g.py tests/test_strategies.py tests/test_module_independence.py tests/test_*figure*.py tests/test_loading_maps.py -q` | ~20 s |
| Full test suite | `python -m pytest -q` | ~12 min |
| pandapower integration S0–S4 | `python -m integration.coordinator --output results/ieee8500/integration --frozen-taps` | ~15 min |
| EVCS S1 study (15 min) | `python -m integration.s1_study` | ~35 min |
| EVCS siting screening | `python -m integration.evcs_screening --resweep` | ~1.5 h |
| Curated `paper/` folder (Figs. 1–8, tables) | `python paper/gerar_pasta_paper.py . paper` | minutes |
| Revised Figs. 1 and 5 | `python revisao_figuras/scripts/make_fig01_rev11.py` · `python revisao_figuras/scripts/make_fig05.py` | seconds |
| OpenDSS audit checks | see `validation_applied_energy_final/README.md` | varies |

Before running the revised Fig. 5 script, run the integration step so that `results/ieee8500/integration/dados/` exists. The OpenDSS steps also need the saved S0–S4 injections from the integration run. See `opendss_rebuild/README.md` and `validation_applied_energy_final/README.md`.

**Checked when this snapshot was published (12 Nov 2026, Windows, Python 3.13):**
- The fast tests pass (79 passed, 35 subtests).
- The revised Fig. 1, Fig. 5 and Fig. 10 scripts run from this repository layout. The Fig. 1 and Fig. 5 outputs are byte-identical to the published figures.

The full suite and the OpenDSS replays were not rerun for this snapshot.

## Known limitations reviewers should weigh

The documents below state these limitations in detail:
- `paper/01_metodologia/metodologia.md`: assumptions about fleet, load curve, costs and zoning.
- `paper/01_metodologia/sensibilidade.md`: line-loading results are robust across the sensitivity cases, but minimum voltage ≥ 0.95 p.u. is not.
- `validation_applied_energy_final/08_pendencias_para_applied_energy.md` and `09_relatorio_final.md`: open items of the OpenDSS validation.
